3. Vérifier les propositions

Une proposition correspond à un départ puis retour près du même point. Le calcul est volontairement prudent : valide chaque suppression.
Charge une trace pour commencer.

4. Arrêts et points d’intérêt

Détecter les pauses d’au moins 10 min et les nuits (si les heures GPS sont enregistrées). Les POI publics sont chargés uniquement sur demande.

Créer une clé sur Geoapify. Les coordonnées recherchées sont transmises au fournisseur choisi.

Pour commencer, sélectionne une seule journée dans « Explorer ». Une recherche sur tout le voyage est possible mais plus longue.

Clique sur la carte pour ajouter un point personnel (activer ci-dessous).

5. Photos géolocalisées

Les photos sont conservées, même sans GPS. Les photos sans position ne sont pas affichées sur la carte.

6. Vidéos du voyage (test)

Importe les vidéos : géolocalisation GPS si disponible, sinon rapprochement avec les horaires GPX. Aucun fichier vidéo n’est envoyé au serveur.

Les positions automatiques sont proposées si les métadonnées sont suffisantes. Sinon, clique sur « Placer sur la carte ». Les horaires incorrects peuvent nécessiter un autre fuseau.

Attention : supprimer une impasse raccorde directement les points d'entrée et de sortie. Cela ne crée pas une nouvelle piste et ne garantit pas la praticabilité de l'itinéraire. Vérifier sur carte avant navigation.
